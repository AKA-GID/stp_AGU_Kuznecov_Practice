# Практическая №8

## Тема: Массивы, контейнеры стандартной библиотеки и класс `Library`

В работе сравниваются массивы фиксированного размера и динамический `std::vector`, а также создаётся класс библиотеки, который инкапсулирует коллекцию книг.

### Часть 1. C-style массивы

- Создаётся массив из пяти книг и выводится циклом с индексом.
- `average_pages()` получает размер массива отдельным параметром: при передаче в функцию массив не хранит информацию о длине.
- Выход за границы показан в виде закомментированного примера. Такой доступ вызывает неопределённое поведение и не должен запускаться.

### Часть 2. `std::array`

- Фиксированный массив выводится индексным и range-based циклами.
- Размер доступен через `size()`, а `average_pages()` получает размер из типа.
- `at()` проверяет границы и выбрасывает `std::out_of_range`; пример перехватывает это исключение. `operator[]` такой проверки не выполняет.

### Часть 3. `std::vector`

- Вектор расширяется через `push_back()`, сокращается через `pop_back()` и `erase()`.
- `resize()` демонстрирует увеличение вектора с указанной книгой-заполнителем. Для уменьшения хвост удаляется через `erase()`: `resize(2)` требует, чтобы `Book` поддерживал создание без аргументов, что противоречило бы обязательным корректным данным книги.
- После каждой операции выводятся размер и содержимое коллекции.

### Часть 4. Класс `Library`

- `Library` хранит книги в `std::vector<Book>`, добавляет книгу, удаляет её по индексу и сообщает текущий размер.
- Удаление с отрицательным индексом или индексом за пределами коллекции безопасно игнорируется.
- Перегруженный `operator<<` выводит каждую книгу на отдельной строке.
- `std::vector` подходит для библиотеки с меняющимся числом книг: не требует заранее выбирать вместимость и хранит только добавленные элементы. C-style массив и `std::array` фиксированы по размеру.

Дополнительные пояснения к границам массивов, `resize()` и трактовке индекса `id` собраны в [уточнениях к работе](Practice_eight_Notes.md).

## Что реализовано в примере

- C-style массив и ручная передача его размера.

- `std::vector` с добавлением, удалением и изменением размера.
