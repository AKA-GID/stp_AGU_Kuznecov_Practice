# Практическая №6

## Тема: Перегрузка методов и операторов

Реализуйте двумерный вектор `Vector2D` с координатами `x` и `y`. Длина вектора вычисляется как `sqrt(x*x + y*y)`. Класс хранит координаты в закрытых полях и предоставляет геттеры.

### Часть 1. Перегрузка `scale()`

Добавьте три метода:

```cpp
Vector2D scale(double factor) const;        // возвращает масштабированный вектор
Vector2D scale(double fx, double fy) const; // отдельно масштабирует оси
void scale(double factor);                  // изменяет текущий объект
```

Покажите вызов всех трёх версий. Унарные версии различаются ещё и `const`-квалификатором: для вызова возвращающей версии используйте константный объект или ссылку на него, а изменяющая версия вызывается на неконстантном объекте.

### Часть 2. Операторы сравнения

Сравнивайте векторы по длине. Реализуйте напрямую только `==` и `<`, а остальные выразите через них:

- `!=` — отрицание `==`;
- `>` — `other < *this`;
- `<=` — `!(other < *this)`;
- `>=` — `!(*this < other)`.

В программе проверьте все шесть операторов на векторах разной и одинаковой длины.

### Часть 3. Арифметические операторы

Реализуйте покоординатные `+`, `-`, `+=`, `-=`, унарный минус, умножение на скаляр и деление на скаляр. Операторы `+=` и `-=` изменяют текущий объект и возвращают ссылку на него. Деление на ноль должно выбрасывать `std::invalid_argument`.

### Часть 4. Умножение скаляра слева

Добавьте свободный оператор:

```cpp
Vector2D operator*(double factor, const Vector2D& v);
```

Проверьте, что `v * 2.0` и `2.0 * v` дают одинаковые координаты.

### Часть 5. `friend`-функция

Объявите свободный оператор `operator*(double, const Vector2D&)` другом класса и реализуйте его с прямым доступом к `x_` и `y_`. Убедитесь, что оба порядка умножения работают.
