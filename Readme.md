# Часть 1. Сеттеры с валидацией

**Задача:** Добавить в класс `Book` возможность обновлять данные книги с проверкой корректности.

Добавьте приватный метод `isValidData()`:

```cpp
bool isValidData(std::string title, std::string author, int year, int pages) const;
```

Метод должен проверять:

- `title` и `author` не пустые
- `year` находится в диапазоне от 1450 (изобретение печатного станка) до 2025
- `pages` больше 0

Добавьте публичные сеттеры:

```cpp
void updateTitle(std::string new_title);
void updateAuthor(std::string new_author);
void updateYear(int new_year);
void updatePages(int new_pages);
```

**Важно:** каждый сеттер должен:

1. Проверять новое значение через `isValidData()`
2. Если значение невалидно — выбрасывать `std::invalid_argument` с понятным сообщением
3. Если валидно — обновлять соответствующее поле

Протестируйте в `main.cpp`:

1. Создайте книгу
2. Попробуйте обновить год на 3000 — должно выброситься исключение
3. Обработайте исключение через `try/catch`
4. Успешно обновите название книги

# Часть 2. Методы vs свободные функции

## Операция 1: Форматирование информации о книге

Функция должна возвращать строку в формате:
```cpp
"Title: <title>, Author: <author>, Year: <year>, Pages: <pages>, Status: <Available/Checked Out>"
```

## Операция 2: Проверка, является ли книга классикой

Книга считается классикой, если она опубликована более 50 лет назад (до 1975 года).

## Операция 3: Вычисление «скорости чтения»

Функция принимает количество страниц, которое читатель прочитывает в день, и возвращает, за сколько дней будет прочитана книга.

```cpp
double readingTime(int pages_per_day);
```

## Операция 4: Сравнение двух книг по году издания

Функция принимает две книги и возвращает `true`, если первая книга старше второй.

- Есть ли методы, которые не используют внутреннее состояние объекта?
- Есть ли методы, которые можно вынести за пределы класса?

Выполните рефакторинг:

- Вынесите все методы, которые не являются частью основной ответственности класса `Book`, в свободные функции.
