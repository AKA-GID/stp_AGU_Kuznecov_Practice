## Часть 3. Const-ссылки

**Задача:** Реализовать функцию, которая сравнивает две книги по году издания, используя const-ссылки.

Добавьте функцию в `book.h`:

```cpp

```

Реализуйте функцию в `book.cpp`.

Измените `main.cpp`. Добавьте сравнение двух книг по году издания с помощью функции `is_older` и выведите результат в консоль.

**Ответьте на вопросы:**

1. Почему мы используем `const Book&`, а не просто `Book&`?
2. Что произойдет, если внутри функции `is_older()` попытаться изменить `b1` или `b2`?
3. В чем преимущество `const T&` перед `T` для больших объектов?

**Эксперимент:**

- Попробуйте изменить `is_older()` так, чтобы она принимала `Book` по значению (`bool is_older(Book b1, Book b2)`).
  Запустите программу. Работает ли она? В чем разница?
- Попробуйте изменить `is_older()` так, чтобы она принимала `Book&` без `const`. Что произойдет, если вы попытаетесь передать константный объект?
