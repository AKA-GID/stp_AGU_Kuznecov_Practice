# Практическая №7

## Тема: Перегрузка операторов, виртуальные методы и абстрактные классы

Практическая работа демонстрирует форматированный вывод объектов, динамический полиморфизм, абстрактную базу фигур и виртуальные деструкторы.

### Часть 1. Перегрузка вывода `Vector2D`

- Свободный `operator<<` выводит вектор как `(x, y)` и возвращает поток, поэтому поддерживается цепочка вывода.
- `to_string()` создаёт строковое представление того же вектора.
- В `main.cpp` показаны оба способа вывода и их сравнение.

### Часть 2. Виртуальные методы `Vector3D`

- `Vector3D` наследует `Vector2D` и добавляет координату `z`.
- Виртуальный `length()` вычисляет длину с учётом размерности объекта.
- `describe()` переопределён в `Vector3D`; вызовы через указатели `Vector2D*` показывают динамический полиморфизм.

### Часть 3. Абстрактный класс `Shape`

- `Shape` задаёт чисто виртуальные `area()`, `perimeter()` и `name()` и описание по умолчанию.
- `operator<<` выводит описание любой фигуры через виртуальный метод.
- `Circle`, `Rectangle` и `Triangle` реализуют интерфейс; площадь треугольника вычисляется по формуле Герона.
- Конструкторы проверяют положительность размеров, а треугольник также проверяет неравенство треугольника.
- Массив указателей `Shape*` выводит все фигуры одним полиморфным циклом.

### Часть 4. Виртуальный деструктор

- В `Shape` определён виртуальный деструктор, чтобы удаление наследника через `Shape*` вызывало деструктор конкретного класса.
- `Circle` печатает `Circle destroyed`, когда уничтожается. Пример с `delete` через базовый указатель демонстрирует вызов деструктора наследника.
- Виртуальный деструктор намеренно оставлен в итоговом коде: удаление через базовый указатель без него приводит к неопределённому поведению.

### Сборка и запуск

Из каталога `Practice_seven`:

```sh
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp vector2d.cpp vector3d.cpp shape.cpp circle.cpp rectangle.cpp triangle.cpp -o practice_seven
./practice_seven
```

## Что реализовано в примере

- Потоковый вывод и `to_string()` для `Vector2D`.
- Динамический полиморфизм `Vector2D` и `Vector3D` для длины и описания.
- Абстрактная иерархия `Shape`, `Circle`, `Rectangle` и `Triangle`.
- Перегрузка `operator<<` для фигур и демонстрация безопасного виртуального деструктора.
