# Уточнение к работе

## Класс и вычисление длины

```cpp
class Vector2D {
public:
    Vector2D(double x = 0.0, double y = 0.0);
    double x() const;
private:
    double x_;
    double y_;
};
```

`class` объявляет пользовательский тип; после тела класса ставится `;`. `public` содержит интерфейс, `private` закрывает координаты. Параметры конструктора имеют значения по умолчанию, поэтому допустимы `Vector2D v;` и `Vector2D v(3.0, 4.0);`. Список инициализации (`: x_(x), y_(y)`) задаёт исходные значения полей.

Методы `x() const` и `y() const` обещают не менять объект. Длина двумерного вектора вычисляется как `std::sqrt(x_ * x_ + y_ * y_)`; `<cmath>` объявляет `std::sqrt`.

## Перегрузка методов

Перегрузка означает несколько функций с одинаковым именем и различными сигнатурами. Компилятор выбирает вариант по числу и типам аргументов, а также по `const`-состоянию объекта.

```cpp
Vector2D scale(double factor) const;
Vector2D scale(double fx, double fy) const;
void scale(double factor);
```

Два однопараметрических метода различаются `const` после списка параметров. На изменяемом объекте вызов `v.scale(2.0)` выберет неконстантный вариант `void`; чтобы получить новый вектор, вызовите константную версию через `const Vector2D& read_only = v; read_only.scale(2.0);`. Вариант с двумя коэффициентами масштабирует оси независимо.

## Перегрузка операторов

Метод `Vector2D operator+(const Vector2D& other) const` позволяет записать `a + b`; слева передаётся скрытый `*this`, справа — `other`. Возвращаемый объект по значению — новый вектор. Оператор присваивания с суммой возвращает `Vector2D&`, чтобы поддержать цепочки выражений и сохранить ссылку на изменённый объект.

- `operator-()` без параметров — унарный минус, поэтому выражение `-v` меняет знак координат.
- `operator*(double)` — умножение вектора справа на число; `operator/(double)` делает деление и проверяет нулевой делитель.
- Сравнения в этой работе относятся к длинам, а не к координатам: `==` и `<` задают основу для остальных четырёх операций.
- `std::invalid_argument` сигнализирует о недопустимом делителе; `try/catch` позволяет показать ошибку.

## Свободная и дружественная функция

Оператор `v * 2.0` — метод объекта `v`, но `2.0 * v` не может быть его вызовом: левый операнд не является `Vector2D`. Поэтому нужен свободный оператор с параметрами `(double, const Vector2D&)`.

```cpp
friend Vector2D operator*(double factor, const Vector2D& v);
```

`friend` разрешает этой функции обращаться к `private`-координатам; сама функция остаётся свободной, а не методом класса. Её определение размещается вне тела класса в `.cpp`. В этой реализации прямой доступ к `x_` и `y_` демонстрирует роль `friend`; обычно достаточно публичных геттеров.
