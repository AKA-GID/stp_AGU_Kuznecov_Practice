# Уточнение к работе

## Передача по значению

```cpp
void change(Book book_copy);
change(book);
```

Параметр `Book book_copy` — самостоятельная копия объекта. Изменения внутри функции не меняют исходную книгу. Передача по значению удобна, когда функции нужна собственная копия, но копирование больших объектов требует дополнительных затрат.

## Передача по ссылке

```cpp
void swap_titles_by_reference(Book& first, Book& second);
```

`Book&` — ссылка на уже созданный объект. Переменная-ссылка должна быть сразу связана с объектом (`Book& alias = book;`), отдельного объекта-копии не создаёт. Изменение через ссылку меняет исходную книгу. Ссылку нельзя позже перенаправить на другой объект.

## Константная ссылка

```cpp
bool is_older(const Book& first, const Book& second);
```

`const Book&` передаёт книгу без копирования и запрещает функции менять её через параметры. Это подходит для чтения и сравнения. Метод `year() const` доступен через такую ссылку; `updateYear()` — нет. Обычная ссылка `Book&` не может привязаться к константному объекту.

## Указатель

```cpp
void swap_titles_by_pointer(Book* first, Book* second);
swap_titles_by_pointer(&book1, &book2);
```

- `Book*` хранит адрес книги, а оператор `&` получает адрес переменной.
- `*first` разыменовывает адрес; `first->title()` равнозначно `(*first).title()`.
- Указатель может иметь значение `nullptr`, поэтому его проверяют до разыменования.
- `const Book*` запрещает изменять объект через указатель. `Book* const` фиксирует сам адрес, но разрешает менять книгу.

Передача указателя позволяет обозначить необязательный объект: `nullptr` означает, что объекта нет. Функция должна безопасно обработать этот случай.

## Свободные функции и проверка результата

Функции `swap_titles_by_value`, `swap_titles_by_reference`, `is_older`, `swap_titles_by_pointer` и `is_book_available` объявляются вне `Book`. Их объявления в `Book.h` и определения в `Book.cpp` должны иметь одинаковые типы и порядок параметров.

Тесты сравнивают реальные названия до и после каждого вызова. Так видно, что копия при передаче по значению не меняет оригинал, ссылка и указатель меняют, а `nullptr` игнорируется без разыменования. Workflow отдельно запускает демонстрационный `main.cpp` и тестовый исполняемый файл; строки `[PASS]` появляются в логах Actions.
