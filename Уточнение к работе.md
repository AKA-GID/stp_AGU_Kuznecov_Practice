# Уточнение к работе

## Класс, поля и методы

`class Book { ... };` объявляет тип; точка с запятой после `}` обязательна. Раздел `public:` содержит доступные клиентам методы, а `private:` скрывает данные и внутреннюю проверку `isValidData()`.

```cpp
Book(std::string title, std::string author, int year, int pages)
    : title_(title), author_(author), year_(year), pages_(pages) {}
```

Конструктор совпадает именем с классом и не имеет типа результата. Аргументы передаются при создании `Book b("1984", "Orwell", 1949, 328);`. Список после `:` — список инициализации: он устанавливает поля до выполнения тела конструктора. Суффикс `_` — соглашение для отличия полей от параметров.

`const std::string& title() const` возвращает строку по константной ссылке без копирования. `const` перед типом запрещает менять строку через результат; `const` после `()` обещает, что метод не изменяет объект. `int` подходит для целых года и числа страниц, `bool` — для доступности и результата проверки.

## Сеттеры и валидация

Сеттер принимает новое значение по значению, например `void updateYear(int new_year)`. Сначала `isValidData(...)` проверяет кандидат вместе с остальными полями. Только после успешной проверки выполняется присваивание `year_ = new_year;`. Это сохраняет согласованное состояние объекта.

`if (...) { ... }` выполняет блок при истинном условии. Проверка `title.empty()` определяет пустую строку, `year < 1450 || year > 2025` проверяет диапазон, `pages <= 0` исключает нулевое и отрицательное число страниц. `||` означает логическое «или», `&&` — «и».

```cpp
try {
    book.updateYear(3000);
} catch (const std::invalid_argument& error) {
    std::cout << error.what();
}
```

`throw std::invalid_argument("...")` сигнализирует о недопустимом аргументе. `try` отмечает код, где возможно исключение, а `catch` обрабатывает конкретный тип. Ссылка `const ...&` не копирует исключение; `what()` возвращает его текст.

## Свободные функции из `Book_utils`

`getInfo(const Book&)`, `isClassic(const Book&)`, `readingTime(const Book&, int)` и `isOlder(const Book&, const Book&)` объявлены вне класса. `const Book&` передаёт книгу без копии и запрещает функции её менять. Эти вычисления и форматирование не меняют состояние книги, поэтому они вынесены из `Book`.

`std::to_string(book.year())` переводит число в строку. `std::string + std::string` склеивает фрагменты результата. `readingTime` делит страницы на число страниц за день; проверка `pages_per_day <= 0` не допускает деление на ноль. В `tests.cpp` эти функции и сеттеры проверяются на корректных данных, границах и исключениях.

## Разделение файлов и сборка

`.h` содержит объявления, чтобы другие исходные файлы знали интерфейс. `.cpp` содержит определения. Линкер соединяет определения с вызовами, поэтому для тестов нужно компилировать `Book.cpp`, `Book_utils.cpp` и `tests.cpp` вместе. GitHub Actions также собирает и показывает запуск демонстрационного `main.cpp`.
