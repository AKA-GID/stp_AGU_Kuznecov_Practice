# Уточнение к работе

## Открытое наследование

```cpp
class RareBook : public Book {
    // методы и собственные поля
};
```

Запись `: public Book` устанавливает отношение «редкая книга является книгой». Публичные методы базового класса доступны через объект `RareBook`. Закрытые (`private`) поля родителя существуют в базовой части объекта, но производный класс не может читать или менять их напрямую.

## Конструктор и список инициализации

```cpp
RareBook::RareBook(std::string title, std::string author, int year, int pages,
                   double estimated_value)
    : Book(title, author, year, pages), estimated_value_(estimated_value) {}
```

После `::` указывается, что это определение метода класса `RareBook`. Список инициализации после `:` вызывает нужный конструктор базы `Book` и инициализирует поле наследника. Сначала конструируется базовая часть, потом поля производного класса, и лишь затем выполняется тело конструктора. Если не указать `Book(...)`, компилятор попробует вызвать `Book()` без аргументов; такого конструктора нет.

Порядок инициализации полей определяется порядком их объявления в классе, а не порядком в списке. Список всё равно нужно писать в том же порядке, чтобы избежать предупреждений.

## Доступ к родителю и описание

Геттеры `title()`, `author()`, `year()` и `pages()` дают безопасный доступ к данным базы. `Book::description()` — квалифицированный вызов метода родителя через оператор области видимости `::`; результат можно расширить собственной информацией.

Метод с тем же именем в наследнике скрывает базовую версию для прямого вызова на `RareBook`. Чтобы вызов через `Book&` или `Book*` динамически выбрал наследника, базовый метод должен быть `virtual`, а метод наследника — `override`. Без этого вызов выбирается по статическому типу выражения.

## Стоимость, скидка и исключения

`double` хранит оценочную стоимость с дробной частью. Для скидки в процентах расчёт `estimated_value_ *= (1.0 - percent / 100.0)` изменяет поле на месте. Валидация диапазона `[0, 100]` не позволяет отрицательную скидку или итог ниже нуля.

`throw std::invalid_argument("...")` сообщает об ошибочном аргументе. Потенциально ошибочный вызов помещают в `try`; `catch (const std::invalid_argument& error)` обрабатывает конкретный тип исключения. Тесты проверяют создание, унаследованные методы, описание, пересчёт стоимости и отклонение некорректных значений.

## Компиляция нескольких исходников

Заголовки содержат объявления (`Book.h`, `rarebook.h`), реализации находятся в `.cpp`. Для демонстрации и тестов компилятору передаются `Book.cpp`, `Book_utils.cpp`, `rarebook.cpp` и соответствующий файл с `main()`. Два файла с `main()` нельзя объединять в один исполняемый файл; поэтому демонстрация и тесты собираются отдельно.
