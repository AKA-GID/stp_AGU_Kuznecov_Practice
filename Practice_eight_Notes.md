# Уточнения к практической №8

## C-style массив

- Индекс `books[7]` для массива из пяти элементов выходит за границы. В C++ это неопределённое поведение: программа может завершиться, вывести случайные данные или повредить память. Этот эксперимент оставлен только в условии, в рабочем примере строка не запускается.
- При передаче C-style массива в функцию он преобразуется в указатель на первый элемент. Функция не может узнать длину массива, поэтому размер передают отдельно. Ошибка в переданном размере может привести к выходу за границы.

## `std::array`

- `std::array<Book, 5>` хранит фиксированное число элементов и предоставляет `size()`.
- Индекс `operator[]` не проверяет границы. `at()` проверяет индекс и при ошибке выбрасывает `std::out_of_range`.
- Размер фиксирован типом: `std::array<Book, 5>` нельзя динамически расширить.

## `std::vector`

- `push_back()` добавляет элемент; `pop_back()` удаляет последний элемент. Перед `pop_back()` нужно убедиться, что вектор не пуст.
- `erase(begin() + i)` удаляет элемент с индексом `i`; последующие элементы сдвигаются влево.
- `resize(n, value)` использует копию `value` для новых элементов при увеличении размера. Уменьшение размера удаляет элементы с конца.
- В учебном примере `Book` требует заполненные корректные поля и не имеет конструктора без аргументов. Поэтому уменьшение вектора показано удалением хвоста через `erase`: некоторые стандартные библиотеки требуют наличие конструктора по умолчанию даже для `resize(n)` при уменьшении.

## `Library::remove(int id)`

Здесь `id` трактуется как индекс, как указано в условии, а не как отдельный идентификатор книги. Допустимы значения от `0` до `size() - 1`; отрицательные и слишком большие индексы игнорируются. Для пустой библиотеки удаление ничего не делает.

## Почему `std::vector<Book>`

Число книг меняется во время работы, поэтому `std::vector` подходит лучше контейнера с фиксированной вместимостью. Он автоматически управляет размером, предоставляет `size()` и не требует хранить тысячу заранее созданных книг. Для доступа по индексу с проверкой границ можно использовать `.at()`.
